## Basic example

The callout component is dropped in version v6 as it can be replicated with utilities. Padding, margin, border and radius are utilities already, and the accent edge that made a callout a callout is `.border-start-4` plus a `.border-start-{color}` utility. Both only shape an edge that a border style has already drawn, so keep `.border` — or `.border-start` alone — on the element.

##### Conveying meaning to assistive technologies

Relying on color to convey meaning creates a visual cue that assistive technologies, like screen readers, cannot perceive. It's essential that any information represented by color is either apparent from the content itself (e.g., the visible text) or supplemented by alternative methods, such as extra text using the `.visually-hidden` class.
</Callout>

## Themed callouts

Pair `.theme-{color}` with `.theme-subtle` to tint the block and colour its text from the theme slots, instead of laying a translucent background over the page colour. The accent edge stays on the border utilities — `.theme-border` cannot carry it, because it emits the `border` shorthand after the width utilities and would reset the left edge to the default width.

<Example code={getData('theme-colors').map((c) => `<div class="theme-${c.name} theme-subtle p-3 my-3 border rounded border-start-4 border-start-${c.name}">
    New to or unfamiliar with flexbox? Read this CSS Tricks flexbox guide for background, terminology, guidelines, and code snippets.
  </div>`)} />

## Building your own

Where a callout appears often enough to deserve a name, wrap the utilities in a class of your own — that is what the base-modifier approach in [Creating your own](/customize/components/#creating-your-own) describes, and how the callouts on these pages are built.

```scss
.my-callout {
  padding: var(--cui-spacer-3);
  margin: var(--cui-spacer-3) 0;
  border: var(--cui-border-width) solid var(--cui-border-color);
  border-inline-start-width: calc(var(--cui-border-width) * 4);
  border-radius: var(--cui-radius-5);
}

.my-callout-info {
  border-inline-start-color: var(--cui-info);
}
```
