## Example

Provide an option to dismiss or close a component with `.btn-close`. The icon is drawn with a CSS mask, so it takes the element's own `color` — put the button on any surface and it stays legible without a variant class. **Be sure to include text for screen readers**, as we've done with `aria-label`.

<Example code={`<button type="button" class="btn-close" aria-label="Close"></button>`} />

## Disabled
Disabled close buttons change their `opacity`. We've also applied `pointer-events: none` and `user-select: none` to preventing hover and active states from triggering.

<Example code={`<button type="button" class="btn-close" disabled aria-label="Close"></button>`} />

## On a dark surface

A close button takes the color it inherits, so a colored surface needs nothing extra — the same `.btn-close` works on a dark toast, a dark offcanvas or an alert.

<Example class="text-bg-inverse p-3" code={`<button type="button" class="btn-close" aria-label="Close"></button>
  <button type="button" class="btn-close" disabled aria-label="Close"></button>`} />

`data-coreui-theme` on a section flips the tokens but paints nothing by itself, so give that section a surface — `.bg-body` and `.text-body` read the flipped tokens — and the close button follows the text like everything else in it.

<Example code={`<div data-coreui-theme="dark" class="bg-body text-body p-3">
    <button type="button" class="btn-close" aria-label="Close"></button>
    <button type="button" class="btn-close" disabled aria-label="Close"></button>
  </div>`} />

## Customizing

### CSS variables

<ScssDocs file="scss/buttons/_close.scss" capture="close-css-vars" />

Point `--cui-btn-close-icon` at any SVG to replace the glyph. The mask uses its shape only, so whatever color the file carries is ignored.

### SASS variables

<DeprecatedIn version="6.0.0" />

Sass variables set these defaults at build time and are removed in v7. The CSS variables above reach the same values without recompiling, and can be set on a single element.
