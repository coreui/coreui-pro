## How they work

- **Gutters use native CSS `gap` on the row.** Numbered column widths and offsets account for the horizontal gap. Columns do not add gutter padding, and rows do not use negative margins. Add padding to an inner wrapper when your content needs it, for example inside a column that clips its content with `.text-truncate`, so the focus outline of a link stays visible.

- **Gutters start at `1.5rem` (`24px`) wide.** This allows us to match our grid to the [padding and margin spacers](/utilities/margin/) scale.

- **Gutters can be responsively adjusted.** Use breakpoint-specific gutter classes to modify horizontal gutters, vertical gutters, and all gutters.

## Horizontal gutters

`.gx-*` classes can be used to control the horizontal gutter widths. The row stays inside its parent, so larger gutters need neither extra container padding nor an `.overflow-hidden` wrapper:

<Example class="docs-example-cols" code={`<div class="row gx-6 text-center">
    <div class="col">
      <div class="p-4 border bg-4">Custom column padding</div>
    </div>
    <div class="col">
      <div class="p-4 border bg-4">Custom column padding</div>
    </div>
  </div>`} />

## Vertical gutters

`.gy-*` classes can be used to control the gap between wrapped lines. Vertical gaps appear only between lines, without adding space before the first line or after the last:

## No gutters

The gutters between columns in our predefined grid classes can be removed with `.g-0`. This removes the horizontal and vertical gaps, and column widths and offsets update to match.

**Need an edge-to-edge design?** Drop the parent `.container` or `.container-fluid`. Rows no longer need `.mx-0` to prevent gutter overflow.

In practice, here's how it looks. Note you can continue to use this with all other predefined grid classes (including column widths, responsive tiers, reorders, and more).

<Example class="docs-example-row" code={`<div class="row g-0 text-center">
    <div class="col-sm-6 col-md-8">.col-sm-6 .col-md-8</div>
    <div class="col-6 col-md-4">.col-6 .col-md-4</div>
  </div>`} />

## Column widths and offsets

For a span of `s` columns in an `N`-column grid, the width is `(row width + horizontal gap) × s / N − horizontal gap`. An offset of `s` columns uses `(row width + horizontal gap) × s / N`. Mixed numbered spans that add up to `N` fit on one line without counting the items on it.

`.col` shares the space left after the gaps, while `.col-auto` keeps its content width. Numbered column classes outside a `.row` keep their percentage widths.

Use `.g-*`, `.gx-*`, and `.gy-*` to change the gaps of a `.row`. The generic `.gap-*` utilities change `gap` without updating the gutter properties the widths read. In your own CSS, set `--cui-gutter-x` and `--cui-gutter-y` on the row. `--cui-gutter-x` is a registered length, so a font-relative value such as `1.5em` resolves on the row and every column subtracts the same gap.

## Change the gutters

Classes are built from the `$gutters` Sass map. By default it follows the `$spacers` keys, and each class reads the matching `--cui-spacer-*` property, so a runtime override of a spacer also changes its gutter class.

```scss
$grid-gutter-x: 1.5rem;
$gutters: null; // built from $spacers
```

To use fixed values instead, pass your own map.

```scss
$gutters: (
  0: 0,
  1: .25rem,
  2: .5rem,
  3: 1rem,
);
```
