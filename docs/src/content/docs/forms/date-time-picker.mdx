  **Preview.** A new v6 product: it replaces `data-coreui-timepicker="true"` on
  the v1 [date picker](/forms/date-picker/). Composed from the
  [date input](/forms/date-input/#date-and-time) masked field in datetime mode, the
  [calendar](/components/calendar/), and the shared time selection body. The API
  is under review and **will change**. See the
  [v6 migration guide](/migration/v6/).

## Example

<AddedIn version="6.0.0" />

The popup shows the calendar and the time selection side by side. The two halves
own different parts of one value — picking a day keeps the time, picking a time
keeps the day — so the popup does not auto-close.

<Example pro code={`<div class="row">
    <div class="col-lg-6 mb-3">
      <div data-coreui-locale="en-US" data-coreui-date-time-picker></div>
    </div>
  </div>
  <div class="row">
    <div class="col-lg-6">
      <div
        data-coreui-date="2026/03/15 14:30:00"
        data-coreui-locale="en-US"
        data-coreui-date-time-picker></div>
    </div>
  </div>`} />

## Floating labels

The date time picker supports [floating labels](/forms/floating-labels/): set `floatingLabel` and the component renders the label itself — no wrapper markup needed — and the text also becomes the field's accessible name. The mask placeholders stay hidden while the label rests inside the field; focusing any part of the field — the sections or the picker button — floats the label and reveals the mask.

<Example pro code={`<div data-coreui-locale="en-US" data-coreui-floating-label="Appointment" data-coreui-date-time-picker></div>`} />

## Accessibility

The field and the popup answer to the [same keys as the date picker](/forms/date-picker/#keyboard-support): <kbd>Alt</kbd> (<kbd>Option</kbd> on macOS) + <kbd>Arrow Down</kbd> or <kbd>F4</kbd> opens the panel, <kbd>Escape</kbd> closes it and returns focus, and arrows, <kbd>Home</kbd> / <kbd>End</kbd>, and <kbd>Page Down</kbd> / <kbd>Page Up</kbd> (with <kbd>Shift</kbd> for years) move the focused date.

The two halves of the panel are each one tab stop, so <kbd>Tab</kbd> takes three presses to cross it: the navigation, the calendar, the time. Inside the time half, <kbd>Arrow Left</kbd> and <kbd>Arrow Right</kbd> move between the hour, minute, second and AM/PM parts, the same way they move between the sections of the field.

The toggle button carries the panel's state — `aria-haspopup="dialog"`, `aria-controls` pointing at the popup while it is open, and `aria-expanded` tracking whether it is open — so a screen reader announces what the button does and whether the panel is showing. The panel itself is a `dialog` with `aria-modal`, so focus moves into it on open, stays there while it is open, and returns to the field when it closes.

## Usage

### Via data attributes

```html
<div data-coreui-date-time-picker></div>
```

### Via JavaScript

```js
const picker = new coreui.DateTimePicker(element, { locale: 'en-US' })
```

### Options

Options belonging to the inner [calendar](/components/calendar/#options) or
[date input](/forms/date-input/#options) are forwarded by name.

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `allowList` | object | `SVGAllowlist` | Allowlist used when sanitizing the icon markup. |
| `ariaCleanerLabel` | string | `'Clear date and time'` | Accessible label of the cleaner button. |
| `ariaLabel` | string | `'Date and time input'` | Accessible name of the field. It lands on the `role="group"` container the sections sit in, so it names the whole control rather than one part of it. |
| `ariaPickerLabel` | string | `'Toggle calendar and time selection'` | Accessible label of the picker button. |
| `ariaSelectHoursLabel` | string | `'Select hours'` | Accessible name of the hours select in the panel. |
| `ariaSelectMeridiemLabel` | string | `'Select AM/PM'` | Accessible name of the AM/PM select in the panel. |
| `ariaSelectMinutesLabel` | string | `'Select minutes'` | Accessible name of the minutes select in the panel. |
| `ariaSelectSecondsLabel` | string | `'Select seconds'` | Accessible name of the seconds select in the panel. |
| `calendarOptions` | object | `{}` | Programmatic escape hatch for calendar options. |
| `cleaner` | boolean | `true` | Renders a button that clears the value. It appears only once the field holds one. |
| `cleanerIcon` | string | cross SVG | Inline SVG rendered by the component (sanitized). |
| `container` | string, element, false | `false` | Teleport target for the dropdown. |
| `date` | date, string, null | `null` | Initial value (date **and** time). |
| `disabled` | boolean | `false` | Disables the field and the popup. |
| `hours` / `minutes` | array, boolean, function | — | Allowed time values, forwarded to the selection body. |
| `inputOptions` | object | `{}` | Programmatic escape hatch for field options. |
| `locale` | string | browser locale | Drives the mask, the calendar labels, and the 12/24-hour split. |
| `maxDate` / `minDate` | date, string, null | `null` | Bounds, enforced by both layers. |
| `name` | string, null | `null` | Name of the generated hidden input. Without it the field is not submitted with the form. |
| `pickerIcon` | string, boolean | `true` | The button that opens the calendar and time selection: `true` for the built-in icon, an inline SVG string for your own (sanitized), `false` for no button. Without it the popup has no pointer opener and nothing reports the expanded state, though the field keeps the keyboard openers below. |
| `seconds` | array, boolean, function | `true` | `false` drops the panel column and the field's seconds section together. A list or a filter narrows the panel; the field still accepts any second. |
| `selectionOptions` | object | `{}` | Programmatic escape hatch for the selection body. |
| `size` | string, null | `null` | `'sm'` or `'lg'`. |

### Methods

| Method | Description |
| --- | --- |
| `clear` | Clears the value. |
| `dispose` | Destroys the picker and its inner components. |
| `getContext` | Returns the slot context (same shape as the date picker). |
| `getDate` | Returns the current value (`Date` or `null`). |
| `reset` | Restores the initial value. |
| `setDate` | Sets the value and emits `dateChange`. |
| `show` / `hide` / `toggle` | Popup control. |
| `today` | Sets the current date and time. |

### Events

| Event | Description |
| --- | --- |
| `dateChange.coreui.date-time-picker` | Fired when either half changes the value. `event.date` carries the merged `Date`. |
| `show/shown/hide/hidden.coreui.date-time-picker` | Popup lifecycle. |
