## Example

### Days

Two masked fields share one input-group frame; the calendar spans two months and
owns the range mechanics — pick a start day and the selection advances to the
end date automatically. Focusing the end field switches the calendar to
end-date selection, the way clicking the end input does in v1.

<Example pro code={`<div class="row">
    <div class="col-lg-7 mb-3">
      <div data-coreui-locale="en-US" data-coreui-toggle="date-range-picker"></div>
    </div>
  </div>
  <div class="row">
    <div class="col-lg-7">
      <div
        data-coreui-end-date="2026/03/20"
        data-coreui-locale="en-US"
        data-coreui-start-date="2026/03/15"
        data-coreui-toggle="date-range-picker"></div>
    </div>
  </div>`} />

#### With footer

There is no `footer` option — project a `<template data-coreui-template="footer">`
child. With a footer present, completing a range does **not** auto-close;
closing is the footer's job.

<Example pro code={`<div class="row">
    <div class="col-lg-7">
      <div data-coreui-locale="en-US" data-coreui-toggle="date-range-picker">
        <template data-coreui-template="footer">
          <button type="button" class="btn btn-sm btn-ghost-primary" data-coreui-picker-action="clear">Clear</button>
          <button type="button" class="btn btn-sm btn-primary" data-coreui-picker-action="close">OK</button>
        </template>
      </div>
    </div>
  </div>`} />

### Weeks

Add `data-coreui-selection-type="week"` to select week ranges, and
`data-coreui-show-week-number="true"` to show week numbers. The fields render
the native `<input type="week">` presentation (`Week 29, 2026`, with a
localized fixed label) — see the [date picker](/forms/date-picker/#weeks)
note on the ISO week-numbering year.

<Example pro code={`<div class="row">

        data-coreui-selection-type="week"

## Floating labels

The date range picker supports [floating labels](https://coreui.io/bootstrap/docs/forms/floating-labels/): wrap the component in `.form-floating` and put a `<label>` beside it. One label covers the pair — it floats as soon as either date is set or any part of the field has focus. Each field reveals its own mask: with only the start date set, the empty end keeps its mask hidden and the arrow is what says a second date belongs there.

<Example pro code={`<div class="form-floating">
    <div id="floatingExample" data-coreui-locale="en-US" data-coreui-toggle="date-range-picker"></div>
    <label for="floatingExample">Stay dates</label>
  </div>`} />

## Custom ranges

There is no `ranges` option. Project a `<template data-coreui-template="ranges">`
child — it renders as a column beside the calendars. Presets take arguments, so
they run through `getContext().setRange()`: the date math, labels, and order are
yours.

<Example pro code={`<div class="row">
    <div class="col-lg-8">
      <div id="myDateRangePickerRanges">
        <template data-coreui-template="ranges">
          <button type="button" class="btn btn-sm btn-ghost-primary" id="rangeLast7">Last 7 days</button>
          <button type="button" class="btn btn-sm btn-ghost-primary" id="rangeLast30">Last 30 days</button>
          <button type="button" class="btn btn-sm btn-ghost-primary" id="rangeThisMonth">This month</button>
        </template>
        <template data-coreui-template="footer">
          <button type="button" class="btn btn-sm btn-ghost-primary" data-coreui-picker-action="clear">Clear</button>
          <button type="button" class="btn btn-sm btn-primary" data-coreui-picker-action="close">OK</button>
        </template>
      </div>
    </div>
  </div>`} sandboxJs={dateRangePickerRanges} />

renders its mirrored counterpart (`separatorIconRtl`) whenever the picker sits
in an RTL context — the document direction or any `dir="rtl"` ancestor.

## Custom formats

`inputDateFormat` and `inputOnChangeDelay` are gone — the mask defines the
format. Set it with `data-coreui-format`, forwarded to both fields.

## Accessibility

The fields and the popup answer to the [same keys as the date picker](/forms/date-picker/#keyboard-support): <kbd>Alt</kbd> + <kbd>Arrow Down</kbd> or <kbd>F4</kbd> opens the calendars, <kbd>Escape</kbd> closes them and returns focus, and arrows, <kbd>Home</kbd> / <kbd>End</kbd>, and <kbd>Page Down</kbd> / <kbd>Page Up</kbd> (with <kbd>Shift</kbd> for years) move the focused date.

## Usage

### Via data attributes

Add `data-coreui-toggle="date-range-picker"` to a `div` element.

```html
<div data-coreui-toggle="date-range-picker"></div>
```

### Via JavaScript

```html
<div class="my-date-range-picker"></div>
```

```js
const pickerElementList = Array.prototype.slice.call(document.querySelectorAll('.my-date-range-picker'))
const pickerList = pickerElementList.map(pickerEl => {
  return new coreui.DateRangePicker(pickerEl)
})
```

### Options

Options belonging to the inner [calendar](/components/calendar/#options) or
[date input](/forms/date-input/#options) are forwarded by name, so their data
attributes work on the picker element too.

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `allowList` | object | `SVGAllowlist` | Allowlist used when sanitizing icon markup. |
| `ariaCleanerLabel` | string | `'Clear the value'` | Accessible label of the cleaner button. |
| `ariaLabels` | array | `['Start date', 'End date']` | Accessible name of each field, in order. Both halves are the same control, so naming them apart is what tells a screen reader which end of the range it is on. A shorter array leaves the remaining field on its default. |
| `ariaToggleLabel` | string | `'Toggle the calendar'` | Accessible label of the indicator button. |
| `cleaner` | boolean | `true` | Renders a button that clears the value. It appears only once the field holds one. |
| `cleanerIcon` | string | cross SVG | Inline SVG rendered by the component (sanitized). |
| `calendarOptions` | object | `{}` | Programmatic escape hatch for calendar options. |
| `calendars` | number | `2` | Months shown side by side. |
| `container` | string, element, false | `false` | Teleport target for the dropdown. |
| `disabled` | boolean | `false` | Disables the fields and the popup. |
| `endDate` | date, string, null | `null` | Initial end of the range. |
| `endName` | string, null | `null` | Name of the end hidden input. |
| `indicatorIcon` | string | calendar SVG | Inline SVG rendered by the component (sanitized). |
| `inputOptions` | object | `{}` | Programmatic escape hatch for date input options. |
| `locale` | string | browser locale | Drives section order, separators, and calendar labels. |
| `maxDate` | date, string, null | `null` | Upper bound, enforced by both layers. |
| `minDate` | date, string, null | `null` | Lower bound, enforced by both layers. |
| `sanitize` | boolean | `true` | Sanitize the icon markup. |
| `sanitizeFn` | function, null | `null` | Custom sanitizer. |
| `separatorIcon` | string | arrow SVG | Inline SVG between the two fields (LTR). |
| `separatorIconRtl` | string | mirrored arrow SVG | Inline SVG used when the picker renders in an RTL context. |
| `size` | string, null | `null` | `'sm'` or `'lg'`. |
| `startDate` | date, string, null | `null` | Initial start of the range. |
| `startName` | string, null | `null` | Name of the start hidden input. |

### Methods

| Method | Description |
| --- | --- |
| `show` | Opens the popup. |
| `hide` | Closes the popup. |
| `toggle` | Toggles the popup. |
| `getStartDate` | Returns the start of the range (`Date` or `null`). |
| `getEndDate` | Returns the end of the range (`Date` or `null`). |
| `setRange` | Sets both ends and emits both change events. |
| `clear` | Clears the range. |
| `reset` | Restores the initial range. |
| `getContext` | Returns the slot context (see below). |
| `dispose` | Destroys the picker and its inner components. |
| `getInstance` | Static — returns the instance for a DOM element. |
| `getOrCreateInstance` | Static — returns the instance, creating it if needed. |

#### Slot context

```js
const picker = coreui.DateRangePicker.getOrCreateInstance(element)
const context = picker.getContext()

context.setRange(start, end)   // set both ends (null allowed)
context.clear()                // clear the range
context.reset()                // restore the initial range
context.close()                // close the popup
context.startDate              // current start (Date | null)
context.endDate                // current end (Date | null)
context.disabled               // disabled state
```

### Events

| Event | Description |
| --- | --- |
| `startDateChange.coreui.date-range-picker` | Fired when the start changes. `event.date` is formatted per `selectionType`, `event.dateObject` is the `Date`. |
| `endDateChange.coreui.date-range-picker` | Fired when the end changes, with the same payload shape. |
| `show.coreui.date-range-picker` | Fired immediately when `show` is called. |
| `shown.coreui.date-range-picker` | Fired when the popup has been made visible. |
| `hide.coreui.date-range-picker` | Fired immediately when `hide` is called. |
| `hidden.coreui.date-range-picker` | Fired when the popup has been hidden. |

```js
const myPicker = document.getElementById('myPicker')
myPicker.addEventListener('endDateChange.coreui.date-range-picker', event => {
  console.log(event.date, event.dateObject)
})
```
