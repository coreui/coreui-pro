## Example

Wrap the input in a [`form-control-group`](/forms/form-control-group/) and add a `form-control-action` button to give a standard password field a visibility toggle.

<Example pro code={`<div class="mb-3">
    <label for="examplePasswordInput1" class="form-label">Password</label>
    <div class="form-control-group">
      <input type="password" class="form-control" id="examplePasswordInput1" placeholder="Enter your password">
      <button type="button" class="form-control-action" data-coreui-toggle="password" aria-pressed="false" aria-label="Toggle password visibility"></button>
    </div>
  </div>
  <div class="mb-3">
    <label for="examplePasswordInput2" class="form-label">Password with value</label>
    <div class="form-control-group">
      <input type="password" class="form-control" id="examplePasswordInput2" placeholder="Enter your password" value="Top secret">
      <button type="button" class="form-control-action" data-coreui-toggle="password" aria-pressed="false" aria-label="Toggle password visibility"></button>
    </div>
  </div>`} />

## Disabled state

To make a Bootstrap Password Input non-interactive, add the `disabled` attribute to the `<input />` and the toggle `<button>`.

<Example pro code={`<div class="form-control-group">
    <input type="password" class="form-control" placeholder="Disabled password input" disabled>
    <button type="button" class="form-control-action" data-coreui-toggle="password" disabled aria-pressed="false" aria-label="Toggle password visibility"></button>
  </div>
  <div class="form-control-group">
    <input type="password" class="form-control" placeholder="Disabled and readonly input" disabled readonly>
    <button type="button" class="form-control-action" data-coreui-toggle="password" disabled aria-pressed="false" aria-label="Toggle password visibility"></button>
  </div>`} />

## Readonly state

Use the `readonly` attribute to make the input non-editable but still selectable. This is useful for displaying values without allowing user changes.

<Example pro code={`<div class="form-control-group">
    <input type="password" class="form-control" placeholder="Readonly password input" value="Readonly input here..." readonly>
    <button type="button" class="form-control-action" data-coreui-toggle="password" aria-pressed="false" aria-label="Toggle password visibility"></button>
  </div>`} />

## Usage

Via data attributes, the password input plugin toggles visibility of the password by toggling the type of input field. Add `data-coreui-toggle="password"` to the button to toggle a password visibility.

```html
<div class="form-control-group">
  <input type="password" class="form-control" placeholder="Enter your password">
  <button type="button" class="form-control-action" data-coreui-toggle="password" aria-pressed="false" aria-label="Toggle password visibility"></button>
</div>
```

## Customization options

A password field is an `<input>` and a toggle button inside a
[`form-control-group`](/forms/form-control-group/). Almost everything you would
want to change belongs to the group; what this component owns is the icon the
button shows.

### Icons

The plugin renders the icon and swaps it when the password becomes visible, as
inline SVG on `currentColor` — so it follows the button through hover, focus and
disabled without a colour of its own. Pass your own artwork to replace it:

```js
new coreui.PasswordInput('#myPasswordInput', {
  showIcon: '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 16 16" fill="currentColor">…</svg>',
  hideIcon: '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 16 16" fill="currentColor">…</svg>'
})
```

Both are sanitized before they reach the DOM. To pass markup the default
allowlist rejects, extend `allowList`, supply your own `sanitizeFn`, or turn
`sanitize` off for content you control.

### CSS variables

The frame — padding, colours, border, focus ring and the size of the toggle
button, including the icon inside it — is the group's, and it reads the shared
`--cui-control-*` properties. Set them on `.form-control-group` to restyle one
field, or globally to restyle every field component at once:
