<Callout color="warning">
  **Preview.** The in-progress v6 rewrite of the time picker — a composition of
  the [time input](/forms/time-input/) masked field, the shared time selection
  body, and the popup primitive. The API is under review and **will change**;
  the current [time picker](/forms/time-picker/) remains the stable component.
  See the [v6 migration guide](/migration/v6/).
</Callout>

## Example

Type into the masked field or pick from the roll. The two halves share one
value, so typing and picking stay in sync.

<Example pro code={`<div class="row">
    <div class="col-sm-6 col-lg-4 mb-3 mb-sm-0">
      <div data-coreui-locale="en-US" data-coreui-toggle="time-picker"></div>
    </div>
    <div class="col-sm-6 col-lg-4">
      <div data-coreui-locale="en-US" data-coreui-time="14:30:00" data-coreui-toggle="time-picker"></div>
    </div>
  </div>`} />

### Variants

The default `roll` variant shows scrollable columns. Set
`data-coreui-variant="select"` for native dropdowns.

<Example pro code={`<div class="row">
    <div class="col-lg-4">
      <div data-coreui-locale="en-US" data-coreui-variant="select" data-coreui-toggle="time-picker"></div>
    </div>
  </div>`} />

### With footer

There is no `footer` option — project a `<template data-coreui-template="footer">`
child. Buttons act through `data-coreui-picker-action` (`now`, `clear`, `reset`,
`close`).

<Example pro code={`<div class="row">
    <div class="col-lg-4">
      <div data-coreui-locale="en-US" data-coreui-toggle="time-picker">
        <template data-coreui-template="footer">
          <button type="button" class="btn btn-sm btn-ghost-danger me-auto" data-coreui-picker-action="now">Now</button>
          <button type="button" class="btn btn-sm btn-ghost-primary" data-coreui-picker-action="clear">Clear</button>
          <button type="button" class="btn btn-sm btn-primary" data-coreui-picker-action="close">OK</button>
        </template>
      </div>
    </div>
  </div>`} />

## With form field

Wrap the control in [`.form-field`](/forms/field/) to lay it out with its label and description, and to get validation feedback in the right place.

<Example pro code={`<div class="form-field">
    <span class="form-label">Meeting time</span>
    <div data-coreui-locale="en-US" data-coreui-toggle="time-picker"></div>
    <div class="form-text">Local time, in your own time zone.</div>
  </div>`} />

## Floating labels

The time picker supports [floating labels](/forms/floating-labels/): set `floatingLabel` and the component renders the label itself — no wrapper markup needed — and the text also becomes the field's accessible name. The mask placeholders stay hidden while the label rests inside the field; focusing any part of the field — the sections or the picker button — floats the label and reveals the mask.

<Example pro code={`<div data-coreui-locale="en-US" data-coreui-floating-label="Meeting time" data-coreui-toggle="time-picker"></div>`} />

    </div>
  </div>`} />

### Custom hours, minutes and seconds

Pass a list or a filter function through `hours`, `minutes`, and `seconds`.

```js
const picker = new coreui.TimePicker(element, {
  locale: 'en-US',
  hours: [8, 9, 10, 11, 12, 13, 14, 15, 16],
  minutes: minute => minute % 15 === 0,
  seconds: false
})
```

## Usage

### Via data attributes

```html
<div data-coreui-toggle="time-picker"></div>
```

### Via JavaScript

```js
const pickerElementList = Array.prototype.slice.call(document.querySelectorAll('.my-time-picker'))
const pickerList = pickerElementList.map(pickerEl => {
  return new coreui.TimePicker(pickerEl)
})
```

### Options

Options belonging to the inner [time input](/forms/time-input/#options) are
forwarded by name, so their data attributes work on the picker element too.

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `allowList` | object | `SVGAllowlist` | Allowlist used when sanitizing the icon markup. |
| `ariaCleanerLabel` | string | `'Clear the value'` | Accessible label of the cleaner button. |
| `ariaLabel` | string | `'Time input'` | Accessible name of the field. It lands on the `role="group"` container the sections sit in, so it names the whole control rather than one part of it. |
| `ariaSelectHoursLabel` | string | `'Select hours'` | Accessible name of the hours select in the panel. |
| `ariaSelectMeridiemLabel` | string | `'Select AM/PM'` | Accessible name of the AM/PM select in the panel. |
| `ariaSelectMinutesLabel` | string | `'Select minutes'` | Accessible name of the minutes select in the panel. |
| `ariaSelectSecondsLabel` | string | `'Select seconds'` | Accessible name of the seconds select in the panel. |
| `ariaToggleLabel` | string | `'Toggle the time selection'` | Accessible label of the indicator button. |
| `cleaner` | boolean | `true` | Renders a button that clears the value. It appears only once the field holds one. |
| `cleanerIcon` | string | cross SVG | Inline SVG rendered by the component (sanitized). |
| `container` | string, element, false | `false` | Teleport target for the dropdown. |
| `disabled` | boolean | `false` | Disables the field and the popup. |
| `hours` | array, function, null | `null` | Allowed hours — a list or a filter. |
| `indicatorIcon` | string | clock SVG | Inline SVG rendered by the component (sanitized). |
| `inputOptions` | object | `{}` | Programmatic escape hatch for time input options. |
| `locale` | string | browser locale | Drives the mask and the 12/24-hour split. |
| `minutes` | array, boolean, function | `true` | Allowed minutes, or `false` to drop the column. |
| `name` | string, null | `null` | Name of the generated hidden input. |
| `seconds` | array, boolean, function | `true` | Allowed seconds, or `false` to drop the column. |
| `selectionOptions` | object | `{}` | Programmatic escape hatch for the selection body. |
| `size` | string, null | `null` | `'sm'` or `'lg'`. |
| `time` | date, string, null | `null` | Initial value. |
| `variant` | string | `'roll'` | `'roll'` or `'select'`. |

### Methods

| Method | Description |
| --- | --- |
| `show` / `hide` / `toggle` | Popup control. |
| `getTime` | Returns the current value (`Date` or `null`). |
| `setTime` | Sets the value and emits `timeChange`. |
| `now` | Sets the current time. |
| `clear` | Clears the value. |
| `reset` | Restores the initial value. |
| `getContext` | Returns the slot context. |
| `dispose` | Destroys the picker and its inner components. |

#### Slot context

```js
const context = picker.getContext()

context.now()            // set the current time
context.setTime(date)    // set any time
context.clear()          // clear the value
context.reset()          // restore the initial value
context.close()          // close the popup
context.time             // current value (Date | null)
context.disabled         // disabled state
```

### Events

| Event | Description |
| --- | --- |
| `timeChange.coreui.time-picker` | Fired when the value changes. `event.time` carries the new value. |
| `show/shown/hide/hidden.coreui.time-picker` | Popup lifecycle. |
