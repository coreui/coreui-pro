## Colors

Colorize text with color utilities. To colorize a link, give it a [theme class](/customize/theme/) instead — Reboot resolves a link's colour from the theme, and the theme slot carries a hover tone with it. See [link utilities](/utilities/link/).

<Example code={[
  ...getData('theme-colors').map((c) => `<p class="fg-${c.name}">.fg-${c.name}</p>
<p class="fg-emphasis-${c.name}">.fg-emphasis-${c.name}</p>`),
  `<p class="fg-body">.fg-body</p>

<p class="fg-black bg-white">.fg-black</p>
<p class="fg-white bg-black">.fg-white</p>`
]} />

<Callout color="warning">
**Deprecation:** the v5 spellings — `.text-{color}`, `.text-{color}-emphasis`, `.text-body`, `.text-black`, `.text-white`, `.text-reset`, `.text-muted`, `.text-body-secondary`, `.text-body-tertiary`, `.text-black-50` and `.text-white-50` — still ship and render the same, but are removed in v7. Write `.fg-{color}`, `.fg-emphasis-{color}`, `.fg-body`, `.fg-black`, `.fg-white`, `.fg-reset`, `.fg-2`, `.fg-3` and `.fg-black.fg-50`.
</Callout>

<Callout color="info">
##### Conveying meaning to assistive technologies

Relying on color to convey meaning creates a visual cue that assistive technologies, like screen readers, cannot perceive. It's essential that any information represented by color is either apparent from the content itself (e.g., the visible text) or supplemented by alternative methods, such as extra text using the `.visually-hidden` class.
</Callout>

## Foreground ladder

The neutral text hierarchy is a ladder, mirroring the [surface ladder](/utilities/background/#surface-ladder): `.fg-body` is the body text color and the numbers step away from it — `.fg-1` barely, `.fg-4` down to a watermark. The `.fg-{percentage}` opacity utilities compose with all of them.

<Example code={`<p class="fg-body">.fg-body</p>
<p class="fg-1">.fg-1</p>
<p class="fg-2">.fg-2</p>
<p class="fg-3">.fg-3</p>
<p class="fg-4">.fg-4</p>`} />

`.fg-2` and `.fg-3` are deprecated names for `.fg-2` and `.fg-3` — they render identically and go away in v7.

## Opacity

Every `.fg-*` utility writes its colour into `--cui-fg` and reads it back, so a companion `.fg-{percentage}` class can mix that colour with `transparent` through `color-mix()`, in the browser, without recompiling Sass.

```css
.fg-primary {
  --cui-fg: var(--cui-primary-fg);
  color: var(--cui-fg);
}

.fg-50 {
  color: color-mix(in oklch, var(--cui-fg) 50%, transparent);
}
```

Override `--cui-fg` to repaint the utility with another colour; the opacity class keeps working, because it reads whatever the token holds.

<Example class="d-flex flex-column gap-2" code={`<div class="fg-primary">This is default primary text</div>
<div class="fg-primary fg-90">This is 90% opacity primary text</div>
<div class="fg-primary fg-80">This is 80% opacity primary text</div>
<div class="fg-primary fg-70">This is 70% opacity primary text</div>
<div class="fg-primary fg-60">This is 60% opacity primary text</div>
<div class="fg-primary fg-50">This is 50% opacity primary text</div>
<div class="fg-primary fg-40">This is 40% opacity primary text</div>
<div class="fg-primary fg-30">This is 30% opacity primary text</div>
<div class="fg-primary fg-20">This is 20% opacity primary text</div>
<div class="fg-primary fg-10">This is 10% opacity primary text</div>`} />

`.text-opacity-{25|50|75|100}` are the deprecated v5 names of the same knob and are removed in v7.

## Contrast colors

`.fg-contrast-{color}` sets `--cui-fg` to the theme colour's `contrast` slot — the text colour that reads on the solid colour — so a label on a `.bg-{color}` surface picks the right ink without naming it.

<Example code={[
  ...getData('theme-colors').map((c) => `<p class="bg-${c.name} fg-contrast-${c.name} p-2">.fg-contrast-${c.name}</p>`)
]} />

These compose with the opacity utilities too.

<Example class="d-flex flex-column gap-2" code={`<p class="bg-primary fg-contrast-primary fg-100 p-2">.fg-contrast-primary .fg-100</p>
<p class="bg-primary fg-contrast-primary fg-70 p-2">.fg-contrast-primary .fg-70</p>
<p class="bg-primary fg-contrast-primary fg-40 p-2">.fg-contrast-primary .fg-40</p>`} />

## Reset color

Reset a text or link's color with `.fg-reset`, so that it inherits the color from its parent.

<Example code={`<p class="fg-2">
    Secondary body text with a <a href="#" class="fg-reset">reset link</a>.
  </p>`} />

## Specificity

Sometimes contextual classes cannot be applied due to the specificity of another selector. In some cases, a sufficient workaround is to wrap your element's content in a `<div>` or more semantic element with the desired class.
