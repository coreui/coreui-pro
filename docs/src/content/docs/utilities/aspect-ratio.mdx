## Example

Add an aspect ratio class to the element you want to size — an `<iframe>`, a `<video>`, an `<img>`, or a plain `<div>`. The class sets the CSS `aspect-ratio` property, so the element sizes itself; there is no wrapper to add and no child to position.

<Example code={`<iframe class="w-100 ratio-16x9" src="https://www.youtube.com/embed/zpOULjyy-n8?rel=0" title="YouTube video" allowfullscreen></iframe>`} />

<Callout color="info">
**Pro-Tip!** You don't need `frameborder="0"` on your `<iframe>`s as we override that for you in [Reboot](/content/reboot/).
</Callout>

## Aspect ratios

Swap the class for a different ratio. These come from the `$aspect-ratios` map:

<Example class="docs-example-ratios" code={`<div class="ratio-1x1">1x1</div>
  <div class="ratio-4x3">4x3</div>
  <div class="ratio-16x9">16x9</div>
  <div class="ratio-21x9">21x9</div>`} />

They pair with the [width utilities](/utilities/width/) — the ratio decides the height once the width is known.

## Custom ratios

The class sets `--cui-ratio` and a separate rule reads it, so a ratio the map does not name is an inline override away. Use `.ratio-auto` to opt in to the reading rule without picking a named ratio:

<Example class="docs-example-ratios" code={`<div class="w-25 ratio-auto" style="--cui-ratio: 2 / 1;">
    2x1
  </div>`} />

Because it is a custom property, it can also change across breakpoints:

```scss
.ratio-4x3 {
  @include media-breakpoint-up(md) {
    --cui-ratio: 2 / 1;
  }
}
```

<Example class="docs-example-ratios docs-example-ratios-breakpoint" code={`<div class="ratio-4x3">4x3, then 2x1</div>`} />
